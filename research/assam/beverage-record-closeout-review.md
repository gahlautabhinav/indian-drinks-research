# Assam beverage-record close-out review

**Review date:** 2026-10-23  
**Scope:** All 22 canonical Assam rows in `data/beverages.csv`, checked against the current source register, place register, production-method records, cultural-practice records and research-gap register.  
**Review type:** Record-consistency and evidence-scope review. This is not a fresh full-text verification of every cited publication, and it does not certify current production or exhaustive coverage.

## Executive result

- **22/22 Assam beverage rows** have a source-backed ID list whose IDs resolve in the current 90-row source register.
- **22/22** have at least one corresponding place-register row.
- All 22 records already communicate meaningful uncertainty through their evidence/geographic-confidence or open-question fields; this must remain visible in the public archive.
- No beverage should be described as exhaustively mapped or confirmed to be currently made across all listed districts.
- The principal close-out risks are **name/product boundaries**, **process classification**, **source-specific recipe transfer**, **current-practice versus historical evidence**, and **district/community leads being mistaken for village-level production**.

## Cross-register findings

### Source references

A duplicate-source check identified `SRC-090` as a duplicate metadata entry for the same Borah (2026) article recorded canonically as `SRC-084`. The duplicate ID is retained as a retired alias; it must not be counted as an independent publication. The corresponding comparison gap now cites `SRC-084`.


All source IDs listed in the 22 Assam beverage rows resolve to entries in the current source register. This confirms referential integrity, not that every claim in every record is fully supported by the linked source.

### Place coverage

All 22 beverage IDs appear in at least one place-register row. The meaning of that association differs by row: named field locality, starter-culture sample, household sample, district-level study, multi-village scope, GI applicant address or unresolved locality. A place link must not be rendered as proof of present-day production of every linked beverage.

### Production-method coverage

A direct beverage-ID check finds no dedicated production-method row for **ASM-011-JBD (Maibra Jou Bidwi)** in the current method table. This is a documentation gap, not proof that no method source exists. Next action: extract the official GI statement of case and/or a primary field method before creating a source-specific method row. Avoid duplicating a broad Bodo method under a product-specific ID without evidence.

### Cultural-practice coverage

Some records have no direct cultural-practice row, while others have only one source-specific practice. This does not invalidate the beverage identity, but cultural claims should be made only when linked to the appropriate source, community and locality. No ritual or restricted knowledge should be generalized from one community to another.

### Research-gap links

Several research gaps intentionally cover multiple related beverage IDs. Therefore, a gap count calculated by exact string equality against the beverage ID will undercount shared gaps. The correct check must parse semicolon-separated beverage IDs. Open questions in a beverage row should be traceable to a gap record, or explicitly labeled as a lower-priority editorial note.

## Data correction made during this review

Six Assam beverage rows had a stray `;SRC-091` suffix appended to the end of the `Open_Questions` field. It was not a source citation in the `Source_IDs` column and did not belong to the question text. The suffix was removed from those six fields in commit `e992f1308f42b470bc384f7e34abb924c11d6918`. No source list or beverage claim was changed by that correction.

## Close-out actions still required

1. Extract and document the official GI statements of case for Jou Gishi, Maibra Jou Bidwi and Jou Gwran; use their actual specifications rather than broad cultural summaries.
2. Add a source-specific Maibra Jou Bidwi production-method row only after primary-source method extraction.
3. Ensure every substantive open question is represented by a research gap or clearly marked as an editorial follow-up. Parse multi-beverage IDs correctly.
4. Perform source-text verification on the highest-risk process/name claims: Poro Apong, Xajpani terminology, Bodo product boundaries, Haria recipe provenance, and Rohi/Sepa/Black Rohi Modh.
5. Finish the district/community search matrix and record-level gate. Keep author responses and fieldwork-dependent questions open after transition if their limits and next actions are explicit.

## Decision

**Assam is not yet transition-ready.** The inventory has a usable evidence base and no dangling source references in this pass, but it still needs a primary-source GI specification pass, a targeted process/name claim audit, and the district/community search matrix. The aim is a transparent baseline with explicit unresolved questions—not a claim that all Assam beverage traditions have been discovered.
